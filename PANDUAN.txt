APA ITU APLIKASI INI?
---------------------
Auto Typer Pro adalah aplikasi desktop untuk MENGETIK secara
OTOMATIS ke aplikasi lain (browser, Notepad, YouTube Studio,
Excel, form apa saja) dengan pola:

    TEKS UTAMA + NOMOR YANG NAIK TERUS

Contoh:
    Teks utama : dadang film part
    Nomor awal : 3
    Hasil      : dadang film part 3
                 dadang film part 4
                 dadang film part 5
                 ... dst, naik terus sampai kamu tekan F7

==========================================================
ISI PAKET
==========================================================
1. auto_typer.py      -> program utama aplikasi
2. JALANKAN.bat       -> klik 2x untuk langsung memakai app
                         (butuh Python gratis terpasang)
3. build_exe.bat      -> klik 2x untuk membuat file .exe
4. requirements.txt   -> daftar library yang dibutuhkan
5. PANDUAN.txt        -> file yang sedang kamu baca

==========================================================
CARA PALING CEPAT (TANPA PERLU JADI EXE)
==========================================================
Syarat: Python sudah terpasang (gratis, 60 detik).

1. Download & install Python di https://www.python.org/downloads/
   PENTING: saat instalasi, CENTANG "Add Python to PATH"!
2. Klik dua kali file  JALANKAN.bat
3. Aplikasi langsung terbuka. Selesai!

==========================================================
CARA MENJADI FILE .EXE (STANDALONE)
==========================================================
Setelah jadi .exe, aplikasi bisa dibuka TANPA install Python.

1. Klik dua kali file  build_exe.bat
2. Tunggu 1-3 menit sampai muncul tulisan "BERHASIL!"
3. File .exe ada di folder:  dist\AutoTyperPro.exe
4. Salin AutoTyperPro.exe ke desktop mana pun. Selesai!

==========================================================
CARA PAKAI - MODE BIASA (1 KOLOM TUJUAN)
==========================================================
Kalau daftar TARGET dibiarkan KOSONG, aplikasi bekerja seperti
versi sebelumnya: mengetik ke aplikasi yang sedang fokus.

1. Isi TEKS UTAMA:  dadang film part
2. Isi NOMOR AWAL:  3
3. Klik/fokuskan kolom tujuan di aplikasi lain.
4. Tekan F6 -> selama hitungan mundur, klik kolom tujuan.
5. Aplikasi mengetik otomatis: part 3, part 4, part 5, ...
6. Tekan F7 untuk berhenti.

==========================================================
CARA PAKAI - MODE MULTI-TARGET (BARU!)
==========================================================
Kalau daftar TARGET DIISI, aplikasi akan mengklik setiap
target secara berurutan lalu mengetik di sana.

CONTOH: kamu punya 2 target, "Kotak Judul" (jeda 2 dtk) dan
"Tombol Kirim" (klik saja, jeda 1 dtk). Setiap putaran:
    1. Klik Kotak Judul -> ketik "dadang film part 3"
       -> tunggu 2 detik
    2. Klik Tombol Kirim -> tidak mengetik, hanya klik
       -> tunggu 1 detik
    3. Putaran berikutnya: "dadang film part 4" ... dst.

LANGKAH MENAMBAH TARGET:
1. Tekan tombol  + TAMBAH TARGET.
2. Muncul jendela "TAMBAH TARGET BARU" berisi:
   - NAMA TARGET      : nama bebas, mis. "Kotak Judul"
   - POSISI X dan Y   : klik tombol AMBIL POSISI, lalu
                        arahkan mouse ke titik yang mau
                        diklik dan DIAMKAN 5 detik. Angka
                        X,Y otomatis terisi. (Boleh juga
                        mengetik angkanya manual.)
   - JEDA SETELAH TARGET INI (detik)  : mis. 2.0
                        = berapa lama menunggu setelah
                        target ini selesai diproses.
   - Ketik teks di target ini  : centang bila di target
                        ini perlu MENGETIK. Matikan bila
                        hanya ingin MENGKLIK (mis. tombol
                        unggah/kirim).
   - Enter setelah mengetik    : centang bila perlu
                        menekan Enter setelah mengetik.
3. Tekan SIMPAN. Target masuk ke daftar.
4. Ulangi untuk menambah target lain (tidak ada batas).

MENGATUR DAFTAR TARGET:
- EDIT  : pilih target di daftar (klik sekali), lalu tekan
          EDIT. Klik dua kali pada baris target juga bisa.
- HAPUS : pilih target lalu tekan HAPUS.
- NAIK / TURUN : menggeser urutan target. Aplikasi memproses
          target dari atas ke bawah.

OPSI "NOMOR NAIK TIAP SELESAI MENGETIK":
- Dicentang (bawaan): setiap selesai mengetik di sebuah
  target, nomor langsung naik. Contoh 2 target:
  target1 = part 3, target2 = part 4, target1 = part 5, ...
- Tidak dicentang: semua target dalam satu putaran memakai
  nomor yang sama, nomor naik setiap putaran. Contoh:
  target1 = part 3, target2 = part 3, lalu putaran berikut
  part 4, part 4, ...

==========================================================
PENJELASAN TIAP KOLOM
==========================================================
- TEKS UTAMA          : bagian tulisan yang selalu tetap.
- NOMOR AWAL          : nomor pertama yang diketik.
- NAIK TIAP KALI      : berapa kenaikan nomornya.
                        Isi 1 = 3,4,5,6... ; isi 10 = 3,13,23...
- TEKS TAMBAHAN       : tulisan setelah nomor (boleh kosong).
- Spasi otomatis      : memberi spasi antara teks dan nomor.
- JEDA (detik)        : dipakai pada mode biasa (daftar target
                        kosong) sebagai jarak antar pengiriman,
                        dan pada mode multi-target sebagai jeda
                        antar putaran bila jeda target terakhir 0.
- BATAS KIRIM         : 0 = tanpa batas (sampai F7 ditekan).
                        Isi 50 = berhenti sendiri setelah 50
                        ketikan.
- MUNDUR (detik)      : hitungan mundur sebelum mulai.
- Enter otomatis      : dipakai pada mode biasa saja; pada
                        multi-target, Enter diatur per target.
- TARGET (urutan klik): daftar titik klik + pengaturannya.
                        Kosong = mode biasa.

==========================================================
HOTKEY
==========================================================
F6  = MULAI
F7  = BERHENTI (ESC juga bisa)

==========================================================
TIPS PENTING
==========================================================
- Laptop: kadang F6/F7 harus ditekan bersama tombol Fn.
- Kalau nomor kacau / dobel: naikkan JEDA / jeda target.
- Posisi target tergantung posisi jendela aplikasi. Kalau
  jendela aplikasinya dipindah, ambil ulang posisinya (EDIT
  target -> AMBIL POSISI).
- Pengaturan (termasuk daftar target) tersimpan otomatis di
  auto_typer_settings.json di folder yang sama.

==========================================================
TROUBLESHOOTING
==========================================================
Masalah: "pynput belum terpasang"
  -> Buka CMD, jalankan:  pip install pynput
     Atau pakai JALANKAN.bat yang otomatis memasangnya.

Masalah: python tidak dikenali saat klik file .bat
  -> Install ulang Python, CENTANG "Add Python to PATH".

Masalah: hotkey F6 tidak bereaksi
  -> Coba Fn + F6, atau klik tombol MULAI di jendela app.

Masalah: teks masuk ke tempat yang salah
  -> Mode biasa: pastikan kamu mengklik kolom tujuan SELAMA
     hitungan mundur.
     Mode multi-target: periksa kembali posisi X,Y target
     (EDIT target) dan pastikan jendela aplikasi tidak
     dipindah-pindah.
